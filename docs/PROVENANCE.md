# Provenance

BitWeave separates source-controlled inputs from generated outputs.

Tracked in the repository:

1. C11 implementation source in `src/`;
2. canonical tool bitstreams in `canonical/`;
3. forward-authoring examples in `examples/`;
4. tests in `tests/`;
5. documentation and GitHub-native visual assets;
6. CI definitions in `.github/workflows/`.

Not tracked in the repository:

- local build directories;
- compiler/sanitizer logs;
- generated example executables;
- machine-specific verification captures;
- release archives and compiled tool binaries.

Those are regenerated by CI or release builds. This keeps the source tree reviewable while preserving reproducible checks.
